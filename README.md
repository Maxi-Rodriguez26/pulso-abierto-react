# Pulso Abierto

Plataforma web de consulta en tiempo real de precios de criptomonedas (Bitcoin, Ethereum y Solana), desarrollada con React, TypeScript y Zustand, incorporando gestión de estado global, persistencia local y pruebas automatizadas.

## Tecnologías Principales
* React / Vite
* TypeScript
* Zustand (con middleware de persistencia)
* React Router DOM
* Vitest & Testing Library
